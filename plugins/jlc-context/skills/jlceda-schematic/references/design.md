# 器件、引脚与排版

## 器件与连接

- 在已有工程中优先读取实际器件及库关联，不因名字相似就替换成新器件。
- 新器件先确认真实库结果、型号、符号、引脚编号与功能。数据手册或用户给定参数决定电气选择，不能用外观代替参数。
- 引脚编号、引脚名称、器件位号分别处理；旋转、镜像及多单元器件需读取实际变换与单元信息。坐标单位和角度约定以当前 API 文档为准。
- 电源、地、信号、未使用引脚按真实器件要求处理。无法确定的供电范围、引脚用途或必要外围器件标为待确认，不能默认接地。
- 连线端点需落在实际连接点与工程栅格上。交叉、连接点、跨页网络及网络标签作用域以 EDA 原生语义为准，不靠截图猜连接。
- 新建网络与现有网络重名时，检查是否本来就应连通。不要为了消除警告而随意加电源标记、短接网络或给未连接引脚添加无连接标记。
- 进入 PCB 前核对符号引脚与封装焊盘映射。虚拟符号与需要上板的实体元件区别处理；封装名存在不代表封装可解析或尺寸正确。

## 排版

- 根据用户阅读方向与功能块安排布局；连接器、主器件、局部外围和电源网络的位置服务于电路理解。
- 避免文本覆盖符号、引脚、连接点和关键导线；保留分块间距与图页边界。
- 连接较多时，在保持网络语义的前提下使用标签，避免一味拉长导线。网络标签必须明确且作用域正确。
- 新设计按复杂度选择图页和层次；已有工程局部改动不擅自重排所有器件或重构层次。
- 可使用已有导出/预览能力做可读性检查，但预览仅证明外观。图形检查与网络读取分别报告。
- 一次整理可列出并集中修复明确问题；没有具体阻塞问题时不反复移动、重建或追求“完美排版”。
